# نظام الماركت المحاسبي

مشروع جديد مستقل لنظام محاسبي وإداري عربي لسطح المكتب.

## المزايا الحالية
- واجهة عربية بالكامل وباتجاه RTL.
- تبويبات رئيسية في الجهة اليسرى ومحتوى الوحدة في الجهة اليمنى.
- نفس التصميم موحد لجميع الوحدات.
- قاعدة بيانات محلية SQLite.
- إدارة أولية للأصناف والمخزون.
- سجل حركة وتدقيق فعلي للعمليات.
- ملف تثبيت Windows واحد باسم Setup.exe.
- لا يحتاج العميل إلى Python أو Node.js أو npm بعد التثبيت.
- إنشاء اختصار على سطح المكتب وقائمة ابدأ.
- بيانات المستخدم تحفظ خارج مجلد التثبيت داخل مستندات المستخدم.
